# AI 内页统一修改计划（AI视频 / AI图片 通用）

> 适用范围：导航栏「AI视频」（/ai-video-generator）、「AI图片」两个内页，以及后续所有同类内页（如未来音频页）。
> 核心逻辑：所有内页 = 同一套组件 + 各自一份页面配置 + 各自一份文案数据源，差别只有「视频」和「图片」的区别。
> 本文档面向新会话执行：包含现状代码事实、具体文件路径、已有机制说明、每步的可验证产出。执行前请先按「现状事实」一节核对代码，若与文档不符，以代码为准并向用户确认。

## 一、现状事实（执行前核对用）

### 1. 页面与路由

- 首页：`src/app/[locale]/(landing)/page.tsx`
  - 14 个 section 顺序：`hero`、`prompt-showcase`、`showcases-flow`、`logos`、`introduce`、`benefits`、`usage`、`features`、`stats`、`testimonials`、`pricing`、`subscribe`、`faq`、`cta`（`showSections` 数组控制）。
  - 外层套 `LandingGeneratorToggle`（client 组件，路径 `src/shared/blocks/landing-generator-toggle.tsx`）。
- 视频内页：`src/app/[locale]/(landing)/(ai)/ai-video-generator/page.tsx`
  - 导航栏「AI视频」指向 `/ai-video-generator`。
  - 现状（旧结构）：hero（文案取 `ai.video.page` 命名空间）+ 直接嵌入 `VideoGenerator` + faq + cta（faq/cta 复用首页 `landing` 命名空间）。
- 图片内页：`src/app/[locale]/(landing)/(ai)/ai-image-generator/page.tsx`
  - 导航栏「AI图片」指向 `/ai-image-generator`。
  - 现状（旧结构，与视频内页同构）：hero（文案取 `ai.image.page` 命名空间）+ 直接嵌入 `ImageGenerator` + faq + cta（faq/cta 复用首页 `landing` 命名空间）。
- 其他 AI 内页（同目录，暂不在本计划范围）：`(ai)/ai-music-generator`；另有 `(landing)/z-image`（独立路由，与导航 AI 图片是否相关待确认）。
- 布局：`(landing)` 布局统一加 Header（导航）和 Footer。工作台态下隐藏 Footer 的现有机制见「三、5」。

### 2. 首页切换机制（必须复用，不要重写）

- `landing-generator-toggle.tsx`（client）：
  - 监听 `prompt-showcase:generate` CustomEvent（由 prompt-showcase 的 page 模式在点击 Generate 时抛出，`detail` 里带 `PromptShowcaseConfig`）。
  - 状态 `showGenerator`：`false` 渲染原首页 14 sections；`true` 渲染 generator 工作台（图片模式渲染 `ImageGenerator`，传 `initialConfig`）。
  - 切换动画：framer-motion `AnimatePresence`，原首页淡出、工作台淡入上移；左栏输入框「飞入」动画；右栏 chips 依次入场。
  - 工作台态时给 `body` 加 class `generator-workbench-active`，退出时移除——CSS 据此隐藏 Footer（见下）。
- `prompt-showcase.tsx`（`src/shared/blocks/common/prompt-showcase.tsx`）：
  - `variant: 'page' | 'panel'`：page 模式带浮动条/模型条；panel 模式常驻展开（generator 左栏用）。
  - 无 `onGenerate` prop（page 模式）时，通过 CustomEvent `prompt-showcase:generate` 把配置抛给页面层。
  - 导出类型 `PromptShowcaseConfig`：prompt / mode / model / ratio / duration / resolution / quality / imageCount / referenceImage。
  - 模型下拉现状（近期已改）：数据源为 `generator/models.ts` 的 `IMAGE_MODELS`（11 个）和 `VIDEO_MODELS`（23 个），随 mode 切换；下拉项左侧供应商 logo（`/model_icon/*.svg`）+ 右侧模型名，容器 `max-h-72 overflow-y-auto` 限高滚动。
  - 生成按钮现状（近期已改）：prompt 为空时 `disabled` + 灰色（`bg-white/10 text-white/40`），有文字后金色渐变（`#f0c46a → #ddb04f`）可点击。收起态和展开态两个按钮都有此逻辑。
- `generator/image.tsx`（`src/shared/blocks/generator/image.tsx`，seevideo 工作台样式）：
  - `mediaMode === 'video'` 时提前 return 渲染 `<VideoGenerator>`（同页面切换，非路由跳转）；模式胶囊「图片」切回。
  - 接收 `initialConfig` prop（首页交接：prompt、ratio 作为初始值）。
  - 左栏 380/420px 表单卡 + 右栏预览卡；模型选择用 `model-select.tsx` + `models.ts`。
  - **注意**：由于提前 return，TS 会把后面代码里 `mediaMode` 收窄为 `'image'`，不要再写 `mediaMode === 'video'` 比较（曾导致 build 报错，已改为固定样式）。
- `generator/video.tsx`：已重写为 seevideo 视频工作台（模型调用：`/api/ai/providers` 探测 + `MODEL_OPTIONS` 映射 + `/api/ai/generate`（AIMediaType.VIDEO）+ `/api/ai/query` 轮询）。
- `generator/models.ts` + `generator/model-select.tsx`：34 个展示模型 JSON 配置驱动（id/name/icon/badges/description/capabilities/locked/lockedTier/recommended/pricing），锁定卡点击跳 `/pricing#<套餐锚点>`；文案 i18n 在 `zh/en/ai/models.json`（`Record<string, ...>` 类型，用 `dict.models[model.id]` 访问）。

### 3. i18n 现状

- 文件位置：`src/config/locale/messages/{zh,en}/` 下按命名空间分 json：
  - 首页 sections 文案：`landing.json`
  - 图片：`ai/image.json`；视频：`ai/video.json`；模型：`ai/models.json`
- 工作台文案键：`ai/image.json` 的 `generator.workbench.*`（注意嵌套层级是 `ai.image.generator.workbench`，曾因查错层级误判为空）。
  - 现有键示例：`mode_video`（zh「视频」/ en「Video」）、`mode_image`、`quality_standard`（基础/Basic）、`quality_hd`（高清/**High**，已按参考站从 HD 改为 High）、`quality_ultra`（超清/Ultra）。
- video.tsx 用 `useTranslations('ai.video.generator')`。

### 4. 样式现状与已知坑（重要）

- Tailwind 是 **v4**，`theme.css` 颜色映射用 `@theme inline`：工具类里变量**原样内联**，不带 `hsl()` 包装。
- `src/config/style/seevideo-missing.css`：seevideo 风格的所有补充 CSS 统一放这里（用户明确要求 CSS 都进这个文件，不要内联在 tsx、不要新建其他 css）。
  - 已修复的坑：`--border` 曾写成裸三元组 `240 6% 32%`，导致 `border-border/50` 编译出的 `color-mix(...)` 非法、边框整个失效；现已改为 `hsl(240 6% 32%)`（`:root` 和 `.dark` 两处），`--border-subtle` 同理。
  - `.gradient-text` / `.gradient-text-glow` / `.gradient-border` 已重写为纯 CSS（不依赖 Tailwind v3 的 `--tw-gradient-*` 变量）；标题高亮词用 `.title-gradient-text`。
- 提示词 textarea 聚焦样式（近期已改）：`focus-visible:border-primary focus-visible:ring-0 focus-visible:ring-offset-0`——只要边框变黄（--primary），不要任何光圈/offset。
- 工作台单屏：外层 `md:h-[calc(100dvh-4rem)]` + `pt-16`（给 Header 让位），`main` 用 `h-full`；整页不出现滚动条，只有左栏表单内部滚动。**新增内页工作台必须沿用这套高度方案**。
- 右栏「Ready to generate」配置摘要块已按用户要求删除，不要加回来。

### 5. 工作台 Footer 隐藏机制

- `seevideo-missing.css`：`body.generator-workbench-active footer { display: none; }`
- 由 `landing-generator-toggle.tsx` 在进入/退出工作台时加/移除 body class。

## 二、目标

1. 内页采用与首页相同的组件结构（同一渲染器渲染 sections），文本内容每页独立（SEO：每页 h1/描述/FAQ/关键词均不同，避免重复内容页）。
2. 内页 hero 下的 prompt-showcase **不再支持图片/视频切换**，锁定为对应模式（视频页锁 video、图片页锁 image）。
3. 工作台模式胶囊按页面来源区分：**首页保留图片/视频切换交互不变**；内页不再出现切换胶囊，当前模式直接以纯文字标识呈现——
   - 视频侧：zh「AI视频生成」/ en `AI VIDEO GENERATOR`
   - 图片侧：zh「AI图片生成」/ en `AI IMAGE GENERATOR`
4. 后续新增内页零成本：只加一份页面配置 + 两份文案文件。

## 三、改动步骤（含验收点）

### 1. 页面渲染器配置化

- [ ] 新建页面配置文件（建议 `src/config/landing-pages.ts`），每页一份配置对象：
  - `namespace`：文案数据源。首页 `landing`、视频页 `ai.video`、图片页 `ai.image`
  - `lockedMode`：`'video' | 'image' | 'none'`（首页 `none` 保持可切换）
  - `showSections`：该页启用的 section 列表及顺序（默认与首页一致，可按页裁剪）
  - `metadata`：每页独立 title/description/keywords
  - `workbenchMode`：进工作台后是图片还是视频（内页 = lockedMode，首页 none 时按点击时的 mode）
- [ ] 提取统一渲染器（可先放 `landing-generator-toggle.tsx` 同级或 `src/shared/blocks/landing/` 下）：读配置 → 按 `showSections` 渲染 section 组件 → 套 toggle 切换逻辑。
- [ ] 首页 `page.tsx` 改为走同一渲染器（配置 `lockedMode: 'none'`）。**验收：首页行为与改前完全一致**（点 Generate 切工作台、动画、Footer 隐藏、单屏）。
- [ ] 视频内页 `page.tsx` 重写为读配置渲染；图片内页同（先确认其路由路径与现有结构）。
  - **验收：视频页 = 首页同构 sections + 自己的文案 + prompt-showcase 锁定视频**；图片页同理。

### 2. section 组件文案参数化

- [ ] `src/shared/blocks/landing/*` 下各 section 组件：`useTranslations('landing')` 改为 namespace 从 props 传入（由渲染器按配置下发）。组件内部不感知所在页面。
- [ ] 文案文件新增：
  - `zh/en/ai/video.json` 加 `landing` 命名空间（结构对齐 `landing.json` 的 hero/features/faq/cta 等键），内容为视频页专属文案（可与首页不同，SEO 独立）。
  - `zh/en/ai/image.json` 同理。
- [ ] 取数规则：优先读本页 namespace，键缺失回落首页 `landing`（渲染器里做回落，组件不感知）。
- [ ] 每页 `generateMetadata`：title/description/keywords 从各自 namespace 取。
  - **验收：切换 zh/en、切换三个页面，h1 与文案各自独立；`view-source` 中每页 title/description 不同。**

### 3. `prompt-showcase.tsx` 加锁定模式

- [ ] 新增 prop：`lockedMode?: 'video' | 'image'`（不传 = 默认双模式，首页不受影响）。
- [ ] 锁定时：隐藏图片/视频切换胶囊（或只渲染对应选中态、不可点击）。
- [ ] 模型下拉固定使用对应列表（video → `VIDEO_MODELS` 23 个 / image → `IMAGE_MODELS` 11 个），不随交互变化。
- [ ] Generate 事件的 `detail`（`PromptShowcaseConfig`）里 mode 固定为锁定值。
- [ ] 保持既有行为不变：prompt 空 → 禁用 + 灰色；有文字 → 金色渐变；下拉 logo+名称、`max-h-72` 滚动。
  - **验收：视频页/图片页上看不到切换胶囊，模型列表正确，点 Generate 带出正确 mode。**

### 4. `LandingGeneratorToggle` 通用化

- [ ] 接收页面配置（至少 `lockedMode` / `workbenchMode`）：
  - 内页锁定：点击 Generate 直接进对应工作台（视频页永远渲染 `VideoGenerator`，图片页永远渲染 `ImageGenerator`），无模式切换。
  - 首页 `none`：维持现状（按事件里的 mode 决定渲染哪个工作台）。
- [ ] `initialConfig` 交接、framer-motion 切换动画、body class 控制 Footer 隐藏、单屏高度方案全部沿用。
  - **验收：内页点 Generate → 单屏工作台、无 Footer、无滚动条、prompt/配置带入；点导航回首页正常。**

### 5. 工作台模式胶囊：首页保留切换，内页纯文字标识

- [ ] **首页（lockedMode: none）**：工作台模式胶囊保留现有的图片/视频切换交互，行为不变。
- [ ] **内页（lockedMode: video / image）**：胶囊不再是可点击切换的按钮，改为当前模式的纯文字标识：
  - 视频内页：zh「AI视频生成」/ en `AI VIDEO GENERATOR`
  - 图片内页：zh「AI图片生成」/ en `AI IMAGE GENERATOR`
- [ ] `zh/en` 的 `ai/image.json` 中 `generator.workbench.mode_video`、`mode_image` 改值（新文案）；先 grep 确认这两个键是否被其他位置复用，若复用影响别处则新增专用键。
- [x] 实现方式（已落地）：image.tsx / video.tsx 新增 `modeLocked?: boolean` prop（默认 false）——false 时渲染现有可切换胶囊（首页 toggle 不传，行为不变）；true 时渲染为当前模式的纯文字标识（非交互 span，样式保留胶囊底色）。两个内页 page.tsx 嵌入处已传 `modeLocked`。`mode_video`/`mode_image` 键 grep 确认仅这两个工作台使用，改值安全。
- [ ] 样式核对：大写英文文字较长，检查是否溢出，必要时调字号/padding。
  - **验收：首页工作台仍可互切；视频页进工作台只显示「AI视频生成 / AI VIDEO GENERATOR」纯文字，图片页同理，均不可切换、无溢出。**

## 五、不做什么

- 不改首页现有内容与行为（首页只是渲染方式配置化，表现不变）。
- 不改生成逻辑（`/api/ai/generate`、轮询）、模型数据（models.ts）、模型选择组件。
- 不接后端生成。
- 不新建 CSS 文件；seevideo 相关样式一律进 `src/config/style/seevideo-missing.css`。
