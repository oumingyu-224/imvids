> 目标：工作台根据用户当前订阅套餐（价格页 8 个商品之一），动态显示积分消耗与高级功能。
> 本文档是执行依据，事实来源为价格页配置 JSON，不重复维护第二份积分表。

## 一、价格页面所在文件（读取与分类入口）

### 1. 套餐与积分配置（唯一事实来源）

| 内容 | 文件路径 |
|---|---|
| 中文价格页配置 | `src/config/locale/messages/zh/pages/pricing.json` |
| 英文价格页配置 | `src/config/locale/messages/en/pages/pricing.json` |

两个 JSON 结构完全一致，改内容时必须**同时改中英两份**。关键字段说明：

- `pricing.items[]` —— 8 个商品条目（套餐卡），每条含：
  - `product_id`：唯一标识，订阅表 `subscription.productId` 存的就是它
  - `group`：`monthly` / `yearly` / `one-time`
  - `credits`：该套餐总积分；`credits_label: "无限点数"` 表示无限档
  - `amount` / `price` / `unit`：价格展示
  - `is_featured`：推荐标
- `pricing.models.items[]` —— 模型积分表（24+ 条），每条含：
  - `name`：模型显示名（与工作台模型对应）
  - `category`：`video` / `image`
  - `description`：计费说明（按秒、按画质档等）
  - `credits`：**按 product_id 为 key 的积分映射**，值有三种形态：
    - 数字 → 该套餐单次生成积分（含折扣后的 `value` 用 `{ original, value }` 对象表示）
    - `"free"` → 该套餐下无限免费使用（如 premium-monthly 的多数基础模型）
    - `null` → 该套餐不可用该模型（如 Veo 3.1 Premium 的 starter-monthly）
- `pricing.groups[]` —— 三个计费分组 tab
- `messages` —— 价格页文案（含比较表、why-yearly 等）

## 二、套餐识别链路

1. 登录后前端已拿到 `user.currentSubscription`（含 `productId`）。
2. 判定规则：
   - `currentSubscription` 存在且 `status` 为 active、未过期 → 有效套餐
   - 取不到或已过期 → free（免费用户）
3. 新增工具函数 `productId → 档位`，全站统一按档位判断，不做零散字符串比较。

## 三、档位归并（8 个商品 → 4 档）

- **free**：无有效订阅
- **starter（入门版）**：`starter-monthly`、`starter-yearly`、`starter`（一次性）
- **standard（专业版）**：`standard-monthly`、`standard-yearly`、`standard`（一次性）
- **premium（无限制）**：`premium-monthly`、`premium-yearly`

月付 / 年付 / 一次性同档同级，只影响积分价格折扣，不影响功能档位。

## 四、按套餐控制的三类内容

### 1. 模型可用性（显隐 / 锁定）

事实来源：`pricing.models.items[].credits` 中该套餐的值为 `null`。

已知不可用组合（示例）：
- Veo 3.1 Premium：`starter-monthly` / `starter` 不可用
- Kling 2.1 Master：`starter-monthly` / `standard-monthly` / `starter` 不可用（仅年付与一次性）
- Nano Banana Pro：`starter-monthly` / `standard-monthly` / `starter` 不可用

交互规则：
- 模型选择器中不可用模型显示锁标 + 对应升级档提示
- 点击锁定模型 → 弹价格弹窗（复用工作台现有 `showPricingDialog` 机制）
- 现有 `models.ts` 的 `lockedTier: 'pro' | 'max'` 需对齐为 standard / premium

### 2. 积分显示（随套餐联动）

- 工作台「积分 required」由 models.ts 静态 `pricing.credits` 改为：按当前套餐 `product_id` 查 `pricing.models.items[].credits[productId]`
- 取值规则：
  - 数字 → 直接显示
  - `{ original, value }` → 显示折后 `value`
  - `"free"` → 显示「免费」（premium 无限档）
  - `null` → 模型本就不可用，走第 1 条锁定逻辑
- 中英 JSON 都有同一份 credits，运行时按 locale 取对应 JSON 或任取一份（数值一致）

### 3. 高级功能显隐（按档位）

- 分辨率高档位（4K/超清/2K）、多参考图、尾帧、4K 时长档等按档位控制
- 默认基线：premium 全量、standard 中档、starter 基础档、free 最小集
- 具体每个功能对应哪几档，待用户给出「功能 × 档位」清单或确认初稿后落表
