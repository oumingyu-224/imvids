# 模型清单（kie 调用方式）

统一对接方式（kie 文档 Market）：
- 创建任务：`POST https://api.kie.ai/api/v1/jobs/createTask`，body 为 `model` + `input` + 可选 `callBackUrl`
- 查询任务：`GET /market/common/get-task-detail`（用返回的 recordId 换状态与结果）
- 任务状态：waiting / queuing / generating / success / fail
- 鉴权：Bearer Token
