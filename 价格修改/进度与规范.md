## 三、执行规范（必须遵守）

1. **只照抄**：类名、结构、文案逐字来自 DOM，禁止自己设计、优化、判断对错、提替代方案
2. **边界**：用户点名哪一块，只对比、只改那一块；其他部分禁止读、禁止看、禁止出现在思考里
3. **流程**：对比 → 有差异就改，无差异略过 → 报一行结果。不加工序（不提取写 md、不脑内推演、不准备方案）
4. **疑问**：思考中出现任何不确定——哪怕再小——唯一动作是弹提问卡（ask_user）问用户，禁止自己决定、禁止纠结、禁止推演；一次问一个，不积攒
5. **DOM 原文**：提取结果一律写入文件，禁止打印到回复里
6. **修改方式**：精准修改，只动有差异的那一小段，其余一行不碰
7. **验证**：不做本地构建、不起服务；只允许 `tsc --noEmit` / ESLint 静态检查
8. **提交**：用户说「提交代码」= `git add -A` → `git commit` → `git push`，一步到位
9. **回复**：中文、简短、只报结论；不确定就问，不猜
