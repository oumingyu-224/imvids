## 二、三种计费模式（json 归纳）

### 模式 A：限时一折基础模型（premium 无限制）
- 月付（SM/PM）与一次性（OS/OP）= 原价 X（json 里已是打折后的价）
- UM / UY = `free`（无限制）
- SY / PY = X × 0.1 向下取整（json 验证：40→4、100→10、120→12、75→7、30→3 全部吻合）

### 模式 B：SOTA 按秒计费模型（所有套餐均消耗积分）
- 折扣后各套餐值 **以 json 每模型抄录为准**（json 折扣值非精确比例，如 Seedance 2.0 Fast 月专业版 65→50，不能套统一公式）
- 未给出的高档位：先按每秒费率 × 秒数算原价，再乘以该模型最低档的 `value/original` 比例折算

### 模式 C：SOTA 固定价旗舰（非按秒）
- 同模式 B 的套餐折扣，但价格不随时长线性变化（Veo 3.1 Premium、Kling 2.1 Master）
